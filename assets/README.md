# Paper Assets

This directory contains selected final figures from the RSFaith-Bench paper for
quick repository browsing. These files are presentation assets only; intermediate
figure source data, model outputs, claim extraction logs, and LaTeX build
artifacts are not included here.

## Figures

- `figures/teaser.png`: paper teaser.
- `figures/overview.png`: benchmark and evaluation overview.
- `figures/evidence_decomposition.png`: answer accuracy decomposition into FA,
  C-CUR, and M-CUR.
- `figures/model_evidence_diagnostics.png`: model-level evidence diagnostics.
- `figures/subtype_diagnostic.png`: subtype-level diagnostic breakdown.
- `figures/visual_control.png`: visual control analysis.
